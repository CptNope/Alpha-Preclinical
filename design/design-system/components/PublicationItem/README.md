# PublicationItem

One paper in the Publications list: linked title, authors with Alpha scientists in bold, an NLM-style citation, then the links.

- Title Bricolage 600 21px `navy`, hover `tide` underlined. Title and **Read PDF** open the paper.
- Authors `ink-muted` 15px; Alpha authors `<b>` in `navy`.
- Citation: *Journal* (italic 600). Year Mon;Vol(Issue):pages. Epub date.
- Links: Read PDF, PubMed, Free full text (PubMed Central, where one exists), then DOI / PMID / PMCID. Each item also emits `ScholarlyArticle` schema.
- Example: the 2019 *Molecular Therapy* Fabry paper, one of the 16 on the site.
