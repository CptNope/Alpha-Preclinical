# ContourDivider

A single 1.5px `current` wave line: the strata reduced to one contour, used to separate sections without a box or rule.

28px tall, full width, `aria-hidden`. With motion on it draws left to right as the section arrives (2.4s) and rewinds when it leaves. Use sparingly: alternating `mist` and `paper` grounds already separate most sections.
