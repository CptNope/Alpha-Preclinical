# TextLink

Inline links in `tide` (hover `navy`), and an arrow link for "go further" moves at the end of a block.

- `ap-link`: underlined inline link inside running text. 7.1:1 on `paper`.
- `ap-arrow`: bold `tide` link with a trailing arrow that nudges 4px on hover (pointer devices only). Use for "Need a model that isn't listed?", "All publications".
- On `abyss`, both turn `white` with `shallows` on hover.
- Focus: 3px `current` outline, 3px offset, on every link.
