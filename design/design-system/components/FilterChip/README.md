# FilterChip

Pill toggles that filter the Publications, Blog and Careers lists; the pressed chip fills with `abyss`.

48px tall, `radius-pill`, 1.5px `line` border on `paper`, hover `tide`. State is `aria-pressed`. A count in `<small>` is optional. Pair the list with a `role="status"` live region that announces the result count (WCAG 4.1.3).
