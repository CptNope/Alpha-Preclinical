# ModelRow

A typographic list row for expertise areas and models: name, one line of specifics, and an arrow action. Lists of things are rows, not grids of identical cards.

- Three columns (name 4fr, description 6fr, action 150px), collapsing to one on phones.
- 1.5px `line` rules between rows. Hover fills the row `mist` and eases the padding in 16px (pointer devices only).
- Name in Bricolage 600 30px; description `ink-muted` 16px; action `tide` 600 with arrow.
- Name the actual models and assays in the description, not adjectives.
