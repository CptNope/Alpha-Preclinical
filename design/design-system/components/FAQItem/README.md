# FAQItem

An accordion question: Bricolage 21px question with a round chevron icon; the answer eases open beneath it.

- Button inside the heading, `aria-expanded` plus `aria-controls`; the answer uses `hidden`.
- Icon: 36px circle with a 1.5px `line` border; when open it turns `abyss` with a white chevron and rotates 180°.
- Answers in `ink-muted`. The FAQ also emits `FAQPage` schema on the homepage.
- Example answers are placeholders.
